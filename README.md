# 邻传 · LinDrop

在局域网里的电脑和手机之间，像聊天一样传文件、发文字。

邻传是 Windows 原生客户端，手机通过浏览器扫码接入。每台电脑都能收发和中转，不需要指定一台电脑长期充当服务器，也不依赖云端账号。

当前版本：**0.7.4**。

## 能做什么

- **发现设备，直接发送**：同网段自动发现并连接；支持修改设备名称，电脑之间无需配对码。
- **文字与文件放进同一个对话**：文字自动接收，文件按需确认；文字可在气泡内直接拖选、跨行复制，双击选词；支持展开长消息、文件与文件夹收发。
- **连续滚动**：对话按像素平滑移动，可见消息与文字使用有界缓存，减少重复绘制。
- **大文件直传**：新版电脑直连时协商二进制文件块，减少编码及刷盘等待；进度局部刷新，保留滚动位置。旧版和中转路径自动兼容。
- **拖进来，也能拖出去**：文件可拖入窗口发送；已完整接收或仍在原处的文件，可拖到文件夹或接受文件拖入的其他应用。
- **查看图片和视频**：图片缩略图、点击放大；视频调用 Windows 原生播放组件，支持情况取决于系统解码器。
- **手机扫码互传**：安卓无需安装 APK。扫描电脑 A 后，可选择通过 A 可达的电脑 B 收发文件。
- **节点中转、断点续传、文件共享**：已有可达路径时经其他电脑转发，电脑任务支持恢复；可主动分享指定文件或文件夹。
- **提醒自己决定**：声音、未读角标、标题、任务栏、系统通知、窗口内提示分别开关。

## 开始使用

1. 从本仓库的 [Releases](https://github.com/SteenLuo/lindrop/releases/latest) 下载 Windows 程序包，64位Windows建议选x64，32位Windows选x86；解压后打开 `邻传.exe`。源码压缩包需要自行构建。
2. 每台电脑各运行一份，在左下角“设置”里改成容易辨认的设备名。
3. 在设备列表选择对方，拖入文件或输入文字即可发送。首次接收文件需要在对话中确认。
4. 手机连接同一可达的局域网，用浏览器扫描电脑左下角二维码图标中的二维码。

找不到另一台电脑时，查看对方二维码卡片里的 `IPv4:端口`，在“连接其他设备”中输入。默认端口为 `8776`。跨网段的广播发现通常不可用，但只要一端能建立应用连接，就可在该连接上双向传输。

程序不会修改路由器或防火墙；没有任何可达路径时，不能穿过网络隔离。手机网页在使用期间需要入口电脑在线。

详细操作见 [使用说明](docs/usage.txt)，连接问题见 [常见问题](docs/FAQ.md)。

## 支持的平台

| 平台 | 方式与验证范围 |
| --- | --- |
| Windows 11 | 原生客户端，已在开发机验证 |
| Windows 10 / Windows 7 | 保留兼容目标，提供x64及x86构建；不同系统、解码器及驱动仍需真机验证 |
| 安卓 | 浏览器扫码接入，无需 APK；本次开源整理未重做安卓真机测试 |
| macOS / Linux | 当前不提供桌面客户端 |

使用 Go 1.20.14 是为了保留 Windows 7 编译目标。这一旧工具链已停止接收 Go 官方安全更新，详见 [安全与使用边界](SECURITY.md)。

## 配置保存在什么地方

- 配置与设备身份：`%APPDATA%\LinDropNode\settings.json`。
- 默认接收目录：`%USERPROFILE%\Downloads\LinDrop`，可在设置中更改。
- 同一个 Windows 用户正常启动时，移动程序或替换新版 EXE 会沿用原配置。把程序复制给另一台电脑时，只复制程序包，每台电脑保留独立配置。
- `settings.json` 包含设备私钥、手机会话信息和本地路径，不要上传到仓库或附在公开 Issue 中。完整备份应保留整个 `LinDropNode` 目录。

开发工具若以打包应用身份启动子进程，Windows 可能将 AppData 重定向到工具专属目录。正式升级应从资源管理器启动并核对原名称、历史和连接，不能仅凭开发环境启动结果判断配置已保留。

## 从源码构建

在 Windows 安装 **Go 1.20.14**，将 `go` 加入 PATH。在项目目录执行：

```powershell
.\build.ps1
```

脚本默认先测试再生成32位 `邻传.exe`；64位执行 `.\build.ps1 -Architecture amd64`。依赖已包含在 `vendor/` 中，标准构建不需要下载 Go 模块。用户运行程序不需要 Go、Python、Node、.NET 或浏览器内核。

也可手动运行：

```powershell
$env:GOOS = 'windows'
$env:GOARCH = '386'
$env:CGO_ENABLED = '0'
go test -mod=vendor -v -timeout 150s ./...
go build -mod=vendor -trimpath -ldflags '-H windowsgui -s -w' -o 邻传.exe .
```

图标与窗口清单的编译资源 `rsrc_windows_386.syso` 及 `rsrc_windows_amd64.syso` 已提供。更新资源的步骤见 [开发说明](docs/DEVELOPMENT.md)。
