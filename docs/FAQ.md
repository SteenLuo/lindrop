# 常见问题

## 两台电脑开着却找不到对方

确认两边均运行当前版。自动发现依赖局域网广播，路由器的不同网段、访客网络或设备隔离可能阻断发现。在目标电脑的二维码卡片查看地址，在另一端“连接其他设备”中输入 `IPv4:端口`。网络允许其中一端建立连接，就可在同一连接上双向传输。

`ping` 使用的 ICMP 与邻传连接不是同一协议，单凭 ping 通或不通不能判定邻传一定可用。无可达网络路径时，软件不能穿过隔离；可检查设备网络或连接可达的中转节点。默认 TCP 节点端口为8776，发现使用 UDP 广播。请由网络管理者决定网络策略。

## 升级后名字和记录不见了

先退出软件并备份配置，确认使用的是同一 Windows 用户和同一份配置。正常目录为 `%APPDATA%\LinDropNode`。程序位置不影响默认配置，但不同用户、显式 `-state-dir` 或开发工具的 AppData 虚拟化可能产生不同目录。

不要删除新旧配置来“重置”，也不要把另一台电脑的配置覆盖到本机。从资源管理器启动实际程序，核对原名称、历史和连接。开发工具的专属配置若需恢复，应在双方备份和程序退出后将完整目录迁回普通用户目录。

## 手机换电脑扫码后名称不同

浏览器按入口地址保存资料。首次扫描新电脑时，可选择“沿用局域网名称”，从已连接电脑登记的名字中选择自己的名称；以后该入口会记住。两端电脑均需0.7.1。名称沿用不合并手机会话或历史，也不使用MAC、IMEI或硬件指纹。

## 手机后台没有提醒或传输中断

手机网页受浏览器和系统省电策略限制。传输时尽量保持网页前台；入口电脑退出后，需扫描其他在线电脑。网页不是永久后台节点，后台通知也不保证持续送达。

## 图片或视频打不开

图片要完整接收后才能预览。视频依赖系统原生组件和解码器，不同 Windows 的格式支持可能不同；可选择系统播放器。不要将解码器支持问题等同于文件已损坏，可先对比源与接收文件的SHA256。

## 把软件移到另一文件夹会丢配置吗

同一个 Windows 用户正常启动时不会。配置在用户目录，独立于EXE所在文件夹。备份时保留整个 `LinDropNode` 目录，并把备份当作包含私钥的个人数据保管。
