邻传 0.7.5 · 首次直传免预扫描版客户端

一、开始使用
每台 Windows 电脑复制同一个“邻传.exe”，双击即可打开独立客户端，无需安装浏览器组件或其他运行环境。
64位Windows建议使用x64包；32位Windows使用x86包。两种构建使用同一配置位置和连接协议，可互相传输。
在左侧“设置”页填写容易辨认的名称，例如“书房台式机”“我的笔记本”“剪辑电脑”，点击“保存”。
设备身份、名称、保存位置、连接记录和任务进度保存在当前用户的 AppData\Roaming\LinDropNode 中。给其他电脑复制程序时，不要复制这个配置目录。

二、电脑之间连接
每台电脑均使用0.6或更新版本，同一网段发现后会自动建立连接，选择设备即可发送；不再要求首次配对，也不需要输入六位码。
跨网段广播通常无法自动发现，点击“连接其他设备”，只填写对方的“IPv4:端口”，点击连接。对方地址可从左下角二维码卡片查看。
例如无线电脑192.168.20.10、有线电脑192.168.10.20，只要一边能够建立应用连接，同一条连接可承载双向传输。已建立可用中转路径时也可互传。
仅升级一端时，旧版仍可能要求配对而拒绝新连接，因此请把参与测试的电脑全部更新。先从托盘退出旧程序，再运行新版；不要把其他电脑的配置目录一起复制。
软件记住设备身份及地址，自动重连。不会修改路由器、光猫或防火墙；网络本身不通时，无配对连接也无法穿过隔离。

三、电脑发送和接收
发送：左侧选择目标设备，点击对话底部“＋ 文件”或“文件夹”，也可将文件或文件夹直接拖到窗口。文件夹保留相对层级，空文件夹不传输。
文件接收：在对应设备的对话气泡中点击“接收”。右键点击待接收任务，选择“接收并信任此设备”后，同一来源下次可以自动接收。可使用任务旁的“拒绝”处理尚未接收的任务。
对话滚轮采用按像素平滑滚动，滚动条拖动直接定位；缓存有容量上限，切换、缩放或内容变化会更新对应绘制。收到的消息靠左、发出的靠右；文件气泡直接显示状态和进度，操作随气泡滚动。新收到的文字和文件提供提示音；其他对话或后台来信显示设备红色未读数字、传输入口标记及标题未读数，并请求任务栏提示和可点击的系统通知。点击通知打开对应对话。正在查看且已滚到底部的对话自动标记已读；查看旧消息时保留未读，不自动切换设备。文件接收确认仍保留。进度更新不重复提示；启动时不为历史消息响铃，未读计数在本次运行保留。左下角“设置→消息提醒”可分别关闭提示音、设备未读角标、标题未读数、任务栏提示、系统通知、窗口内提示；点击即保存，重启后保留。关闭提示不影响接收和文件确认，重新开启不会为旧消息重复响铃。
文字：在对话底部直接输入，点击“发送”或按 Ctrl+Enter；Enter 换行，中文输入法选词确认不会发送。每台设备各自保留本次运行期间的草稿。
文字最多 64 KiB，自动接收并直接显示在气泡中，无需逐条确认，鼠标移到气泡上时，下方出现小复制按钮；也可右键“复制文字”或选中消息后Ctrl+C。直接按住鼠标在气泡文字上拖动即可选择部分文字，支持同一条消息内跨行选择；Ctrl+C或右键“复制文字”复制选中部分，没有选区时复制整条消息。双击按词或中文字符边界选择，不会弹出或覆盖输入框。右键“全选此条文字”或对话获得焦点时Ctrl+A可选中整条消息；Esc清除选择。折叠长文只划选当前显示部分，展开后可跨段选择全文。当前不支持跨多条消息连续划选。长文字在气泡内“展开全文 / 收起”，不另开窗口，全文不会截断。旧版客户端会将文字作为 TXT 文件接收；接收端需升级到 0.4.1 或更新版本才能免确认，仅升级发送端无法改变旧版接收端的行为。自动接收文字不代表信任设备或自动接收文件。升级前尚在等待的有效文字消息会自动进入接收，已暂停或拒绝的消息不会被擅自恢复。
图片/视频：单张图片显示真实缩略图，点击放大；单个视频显示播放卡片，点击在客户端播放器播放，可暂停/继续或重新播放。图片需完整接收后预览，发出的原文件也可预览。格式或解码器不受系统支持时，可用“系统打开 / 系统播放器”。普通文件与文件夹以不同图标卡片显示，点击打开；文件夹内的媒体仍作为目录处理。
向外拖出：按住消息里的文件卡片、图片或视频，拖到资源管理器文件夹或支持文件拖入的聊天窗口后松开，默认复制，原文件保留。单击图片仍用于预览；文件夹可整份拖出，多文件消息会携带本任务文件。收到的文件必须先完整接收，发送记录使用仍在原处的源文件；文件已移动或删除时会提示。也可右键“复制文件”或选中消息后Ctrl+C，再到目标窗口Ctrl+V。具体聊天软件是否接收由对方支持情况决定。
两台0.7.5或更新的电脑直接连接时，首次发送先显示接收请求，确认后读取源文件、边传边计算全量SHA256，不再发送前整文件预扫描。源端哈希与网络确认等待重叠进行，传输前后仍检查源文件是否改变。数据传完后显示“校验中”，接收端继续刷盘并重新读取完整文件核对；这一最终核对仍需时间，通过后才显示完成。手机、共享、文字、旧节点或中转继续先计算校验值，可能有准备时间。
两台0.7.4或更新的电脑直接连接时，文件自动使用二进制块以减少编码开销，无需设置；仅升级一端或经过中转仍使用兼容路径，因此要获得直传优化请两端一起升级。进度只更新对应气泡，不重建对话或干扰选区。
速度取决于两端网卡、交换机/路由器端口、无线链路、CPU和磁盘中的瓶颈。界面显示字节每秒，100Mbps理论仅12.5MB/s、1Gbps理论125MB/s，实际可用吞吐更低；网线类别不能代表整条路径的速度。有线电脑传给Wi-Fi笔记本仍经过无线链路。
同名文件自动另存，不覆盖已有文件。文件完整接收并通过 SHA256 校验后才显示完成。
默认保存位置为当前用户 Downloads\LinDrop；在“设置”页可更改和打开。

四、共享文件和中转
分享：在“共享”页点击“分享文件”或“分享文件夹”，明确选择允许其他已连接设备下载的内容。分享不会复制原文件，文件修改或新增后需移除旧分享再重新添加。
下载：在“共享”页的左侧选择对方设备，点击“刷新共享”，在列表选中项目，再点击“下载到本机”。
查看自己的分享：点击设备栏底部的本机卡片，或共享页右上角的“我的分享”。移除我的分享只取消分享，保留原文件。

每台电脑都具备中转能力，不需要指定中心主机。例如 A 与 B 都能连接 C，可分别与 C 连接，随后通过 C 互传。
软件优先直接连接；已经存在的可用路径可以自动承担转发。中转节点默认边收边转，不在接收目录保存整份中转文件。
要传输的文件所属设备、目标设备以及当前路径上的中转设备，需要在本次任务期间运行。
中转退出或断网时任务暂停。节点恢复、身份校验和路由恢复后，电脑发送任务会自动尝试继续；也可以选择任务点击“继续”。
如果任何可连接路径都不存在，软件不能穿过网络隔离，需要另找可达节点或排查网络。

五、安卓网页收发
在任一电脑客户端将鼠标移到左下角二维码图标，连接卡片即会悬浮显示。移入卡片继续显示，移开后自动收起，不需要单独关闭窗口。点击入口或键盘 Enter/空格也可显示，Esc 可收起；键盘触发时会保持到焦点移开。
手机连接局域网后扫码即可，不必安装 APK；也可在浏览器打开卡片中的地址并输入手机备用码。
手机收到单张图片可点缩略图放大，单个视频提供播放器控件，也可点击“下载”保存原文件。预览不等于已下载到手机。
手机顶部是当前对话设备选择、在线状态与名称菜单；点击右上角菜单可修改手机名称。首次连接某台电脑会直接展开手机名称栏，例如填“书房手机”，保存后在这台电脑重扫二维码也不重置，重复扫码复用同一个手机身份。不同手机使用各自浏览器记录；同名手机排序按固定身份稳定处理。
首次扫描另一台电脑时，可在展开的手机名称栏选择“沿用局域网名称”，从已连接电脑登记的“书房手机”等名称中点选一次，无需重新打字。名称旁显示来源电脑，两台电脑均需支持0.7.1。没有可用名称或原电脑离线时，仍可手动输入；以后重扫当前入口会保留名字。共享的是名称，不复制手机登录凭证，不合并聊天记录。浏览器拿不到手机MAC/IMEI；不同入口也不能仅凭名字判断是不是同一部手机。
点击手机右上角名称菜单，在“消息提醒”中可独立开关页面提示、振动、设备未读数、标题未读数，自动保存在当前浏览器的此入口下；刷新后保留。手机设置与电脑设置各自独立。手机页面收到新消息显示可点击提示，并在设备选择与页面标题中保留未读数；浏览器支持时短振动。网页关闭、锁屏或后台不保证持续提醒。
手机发送：顶部选择目标电脑，底部直接输入文字并发送；点击左下加号选择文件或文件夹。文字自动接收、收到靠左、发出靠右；长文字原地展开/收起，轻点文字气泡可显示小复制按钮，也可长按选择文字。扫描 A 后，也可以选择列表中的 B；软件通过 A 和其他必要节点把文件送到 B。
接收文件：电脑可以在设备列表选中在线手机并发送。手机当前设备对话中会出现文件气泡，点击“下载”后由浏览器保存。
手机页面已去掉独立共享文件区，电脑端共享页继续保留。电脑给手机发送的文件夹或多个文件打包为 ZIP 流式下载，不先落地到中转电脑。
手机网页期间依赖扫码入口电脑在线。入口退出后请扫描其他在线电脑；不保证原会话无感迁移。
保持网页在前台，锁屏或后台省电可能中断传输。网页不是长期中转节点。

六、断点续传
电脑发送/接收：已接收部分保存在“.邻传未完成”目录中，重启后会按已保存进度继续。不要手动删改这些文件。
免预扫描模式续传时，为计算整个源文件的摘要，可能需要重新读取已传前缀，界面显示“校验续传前缀”；该阶段支持暂停和退出。首次发送偏移为0，不需要扫描前缀。最终校验中请等待结束，失败或重启后可重新协商进度。
接收时中间块写入系统文件缓存，每8MiB边界或文件末尾强制刷盘，最终刷盘并完整校验后才报告成功。突然断电可能需重传最近部分内容，最终校验不一致的文件不会作为完成文件交付。
手机上传暂停或页面关闭后，连接原入口，在同一浏览器选择同一目标及相同文件内容，可协商已有进度继续。文件夹需要重新选择同一文件夹。
更换入口、浏览器或清除网站数据可能改变网页设备身份，需要重新配对与建立任务。
源文件变化后不能拼接原任务，需重新选择并发送。
浏览器下载的暂停/继续由浏览器负责，客户端显示“已完成”表示内容已送达浏览器，不代表已经核实手机磁盘落地。

七、关闭与退出
关闭窗口或设置页中的“最小化到托盘”会继续运行；从任务栏通知区域点击邻传图标可恢复。
使用设置页中的“退出邻传”，或托盘右键“退出”，才会停止节点。不会强制开机启动。
重复双击同一配置的程序会尝试唤起已有窗口，不同时启动两个相同身份节点。

八、兼容与边界
程序按保留Win7编译目标的Go 1.20.14提供Windows x64与x86构建，使用原生Windows窗口和系统自带的GDI+平滑绘制。x86也可在64位Windows运行，但大文件建议使用x64。
Windows 11 开发机已验证；不同系统、浏览器及复杂网络仍需按对应设备实测，不能以本地回环模拟替代。
单文件上限 100 GiB；一次最多 5000 个文件。超长 Windows 路径、FAT32 大于 4 GB 文件等系统限制仍适用。
仅支持局域网 IPv4；网络地址或网卡改变后，必要时退出再打开客户端，让设备重新发现和连接。
各电脑的系统时间请尽量一致，签名请求允许约 5 分钟误差。
电脑节点之间每一跳使用 TLS，保持设备身份核对。中转节点属于可信参与者，可以接触转发内容；并非端到端保密。
手机网页入口使用 HTTP，请在可信局域网使用。本版没有云中转、离线投递、剪映专用适配或常驻安卓后台服务。

真实设备验证建议：先两台新版电脑自动连接并小文件双向收发，再连接第三台测试中转，最后测试家里的有线/无线跨网段。详细测试证据见“验证说明.txt”。
