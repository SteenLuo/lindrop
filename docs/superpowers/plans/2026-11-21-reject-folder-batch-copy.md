# 接收拒绝、多文件夹批次与复制反馈修复

用户报告：只能接收/暂停，不能明确拒绝；一次拖入多个文件夹不能正常发送；复制后缺少可见反馈。

## 实现与范围

来件等待、接收中及暂停时，文件气泡显示“拒绝接收”，右键菜单同样可用。拒绝与接收块/最终保存共用任务锁，决定持久化后仅清理经过位置校验的本任务编号目录中的N.part缓存；不递归删除接收目录、不删除已完成文件或发送端原文件。已完成、校验保存中、发出的任务和文字任务不提供这一操作。拒绝为终止状态，不提供恢复，迟到块和结束请求返回拒绝回执，后台错误不能将其变回暂停。

块确认增加可选status字段，成功路径保持既有offset格式，新版发送端在接收拒绝回执时立即停止；旧版发送端仍可在下次任务协商得知已拒绝。手机上传入口将拒绝回执转为明确错误，并清除页面的旧续传任务编号。主动共享下载的本地拒绝同样停止，不向文件提供端发出删除指令。

多选文件夹收集保留每个顶层目录名，单选文件夹维持原有接收根目录。混合文件/文件夹或不同位置的同名顶层项目按不区分大小写的名称分配序号；保持来源路径和文件内容，继续限制5000个文件，空文件夹仍不传输。

复制成功后显式使固定底栏失效，显示3秒绿色确认；失败仅在实际复制失败时显示原因。文字、文件、消息右键和消息选择复制复用结果反馈；文字查看窗口及手机网页已有反馈沿用。反馈结束使用现有计时器恢复快捷键提示。

## 验证

隔离节点通过真实收发验证两个文件夹的同名子路径及混合顶层文件，检查完整目录与最终文件内容/摘要；Windows HDROP实际解析保留多个Unicode文件夹路径。等待、接收、暂停拒绝分别覆盖缓存清理、原文件与已有文件保留、迟到JSON/二进制块、迟到完成、不可恢复及重启。受控慢连接在真实活动的JSON与二进制发送中拒绝，验证两端终止及在途块不能重建缓存。原生消息气泡在多种比例下检查拒绝入口，远程生产窗口执行真实点击复制路径、剪贴板粘贴内容核对、底栏失效及实际画面保存。本机不显示测试窗口，不操作实际剪贴板和真实设备。双架构完整回归完成后发布0.7.14。
