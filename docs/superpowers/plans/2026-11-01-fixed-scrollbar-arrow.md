# 固定滚动条下箭头

用户在实际运行0.7.12时仍看到两个下箭头。已读取正在运行程序的构建记录确认版本，未替换或重启该程序。此前基于完成绘制的连续画面检查没有覆盖用户出现的大间距旧箭头。

下箭头成为guiMain的独立子窗口，与可变输入面板同级，底边直接锚定固定底栏上沿。拖动输入区上沿时其原生窗口矩形与位置均保持不变；主窗口高度变化时维持与底栏的间距。使用Windows SCROLLBAR主题的DOWN状态绘制，主题不可用时回退DrawFrameControl；不获取输入焦点，单击滚一行，按住350ms后每45ms继续滚动，移出暂停、松开/丢失捕获/禁用时停止。

保留原生SCROLLBAR的上箭头、轨道、滑块与32位滚动语义。通过窗口区域裁剪永久排除其下箭头；调整前先取新旧轨道的较短高度，调整后恢复目标区域，保证原生下箭头在中间布局中也不会露出。用户只能看到固定控件绘制的一个下箭头。

125%/150%原生检查发现分别缩放父面板位置、子控件位置与高度会产生一像素底边偏移。编辑框、原生轨道和固定下箭头均从共同的根窗口物理坐标边界计算矩形，先换算端点再相减；布局跳过条件同时核对实际物理矩形，避免逻辑尺寸相同却保留错误取整。

验收：隐藏窗口在1、1.25、1.5、2倍比例检查固定控件零WM_WINDOWPOSCHANGED、固定屏幕矩形、与底栏对齐，以及原生区域确实排除第二个下箭头。远程生成示例连续捕捉整条轨道，覆盖64至260高度的快速往返、逐像素变化和主窗口变化；检查空白轨道中没有旧箭头，固定下箭头像素稳定。原生鼠标实际按住下箭头验证连续滚动、选区和焦点，再保留原生滑块长文拖动检查。完整x64/x86回归后发布0.7.13。模拟应用比例不替代实体系统DPI与显卡验收，未改配置、身份或传输协议。
