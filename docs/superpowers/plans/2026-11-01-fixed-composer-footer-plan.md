# 固定底栏修复

恢复输入区调整的既定布局：快捷键提示和发送按钮贴住主窗口底部，分隔线只调整其上方的输入区域。

1. 原生父子关系回归先在旧实现失败，确认发送按钮仍属于可变高度输入面板。
2. 拆为输入面板和45逻辑像素固定底栏两个同级窗口；输入面板拥有工具按钮与EDIT，底栏拥有发送按钮并绘制提示。每组批量定位仅包含同父窗口控件。
3. 分隔线变化不移动底栏或发送按钮。主窗口尺寸变化只更新底栏锚点及宽度，保留按钮尺寸和相对基线。保留原生双缓冲、背景清理及按帧调度。
4. 提示和通知只使底栏失效，提示过期时单次更新；页切换保持正常显示/隐藏及Tab导航。
5. 隐藏窗口检查1x/2x几何、零底栏移动；远程生产窗口检查最大化/还原、尺寸变化及禁用按钮下方像素，保留生成示例的实际帧。
6. 完整x86/x64回归后生成0.7.11，核对源码及附件并发布，配置位置沿用。
