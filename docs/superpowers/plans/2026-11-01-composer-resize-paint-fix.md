# 输入区拖动闪烁修复

范围：恢复0.7.7已批准的拖动调整体验，不新增交互或改变消息协议。

1. 用原生WM_SIZE复现高度变化清空行位图；保留回归作为修复前失败证据。
2. 移除高度调整的整窗layout调用；只对对话视口、两个工具按钮和输入框执行NOREDRAW批量定位，统一提交后排队重绘。批量分配失败也用禁止即时绘制的定位回退。
3. 保留消息位图，由原有宽度/高度/缩放/内容键决定是否重建；高度不变时跳过重排；拖动期间跳过常规定时刷新。
4. 本机仅隐藏窗口及内存位图专项验证。远程runner增加可见隔离窗口更新区域与单帧绘制检查，继续完整x64/x86回归。
5. 生成0.7.8独立程序包，校验源码提交与附件，沿用原配置和截图功能。
