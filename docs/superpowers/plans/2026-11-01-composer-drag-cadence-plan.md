# 连续拖动节奏与绘制开销修复

恢复既定拖动功能的响应速度，保留0.7.9的原生面板与防残影机制，不更改交互方案。

1. 对0.7.9用生产WM_MOUSEMOVE消息连续输入120次，记录输入P95、排队P95、布局及绘制次数。保留远程报告供对照。
2. 鼠标移动只替换最新目标高度。活动拖动使用15ms窗口定时器按帧消费，松开补交精确释放点，捕获丢失补交最后记录点；结束/销毁取消调度。
3. 移除连续拖动中的RDW_UPDATENOW。保留原生EDIT必要背景擦除和系统双缓冲，交由正常消息循环绘制。
4. 父窗口只失效分隔线旧位置与新位置间的条带；拖动且有消息时只填补纯色背景，结束后正常更新装饰。消息视口使用实际更新条带的缓冲，滚动位置改变才强制更新全部可见消息。
5. 隐藏/内存验证调度、最终位置及部分像素绘制；远程重复同一连续输入与真实画面像素检查，不能把单次云端测量当作实体电脑帧率保证。
6. 完整x86/x64回归后构建0.7.10，核对附件与源码，沿用原配置。
